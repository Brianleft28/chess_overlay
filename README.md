# Proyecto de Reconocimiento de Tableros de Ajedrez

Este proyecto utiliza visión por computadora para reconocer posiciones de ajedrez a partir de imágenes.

## Estructura del proyecto

- `main.py`: Script principal para ejecutar el reconocimiento.
- `src/`: Código fuente principal.
- `assets/`: Recursos y datos de ejemplo.
- `debug_squares/`: Carpeta para depuración (ignorados por git).
